# R5 - Input Representation

R5 compares three ultrasound image representations for ovarian tumor classification:

- **A - Full image:** original ultrasound image.
- **B - Predicted ROI:** cropped region using a U-Net-predicted mask.
- **C - Reference ROI:** cropped region using the dataset's reference mask.

The U-Net provides auxiliary segmentation. Formal CNN training is performed by `src/classification/run_experiment.py`, while ROIs are generated by `src/classification/generate_rois.py`.

## Notebooks

| Notebook                                     | Purpose                                                                                      |
| -------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `00_verificacion_entrada_segmentacion.ipynb` | Initial verification of segmentation data, including train, validation and test (historical) |
| `01_unet_baseline.ipynb`                     | U-Net training; checkpoint selected by validation Dice                                       |
| `02_evaluacion_unet_baseline.ipynb`          | U-Net evaluation on validation and test (historical)                                         |
| `03_analisis_roi_fallback.ipynb`             | Validation-based analysis of ROI margin and fallback                                         |
| `04_verificacion_rois.ipynb`                 | Verification of 2,000 generated ROIs for B and C                                             |
| `05_analisis_comparacion_abc.ipynb`          | A/B/C comparison using three seeds and paired bootstrap on validation                        |

The workflow follows three stages: **auxiliary segmentation (00 - 02), ROI analysis (03 - 04) and classification comparison (05)**.

### Integration smoke test

`smoke_test_integracion_ABC.ipynb` verifies the A/B/C classification pipeline using ResNet50 and one epoch per condition. It is a technical check, not part of the 27 formal R4/R5 classification runs.

Its outputs are stored in `results/classification/smoke_test_ABC/`.

## Reproducibility Notes

- The U-Net checkpoint is stored in `models/segmentation/unet_baseline_best.pth`. Re-running notebook `01` may overwrite it.
- Notebook `00` inspected test images and masks for integrity; its reports are stored in `results/segmentation/input_verification/`. Its saved outputs reflect an earlier output path.
- Notebook `02` evaluated the U-Net on test (469 images; Dice = 0.6935, IoU = 0.5994). Its validation metrics are also used by notebook `03`.
- The 27 formal R4/R5 classification runs used **train and validation only**. The historical U-Net test evaluation and preliminary classifier evaluations are separate from those runs.
- Avoid re-executing notebooks `00`, `02` or the smoke test without reviewing their outputs and possible overwrites.
