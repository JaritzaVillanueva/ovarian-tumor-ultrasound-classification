# Experimental partition manifests – MMOTU / OTU_2D

This folder defines the experimental partition of the MMOTU / OTU_2D dataset into `train`, `validation` and `test`.

## Frozen partition

The membership of each split is frozen. It must not be regenerated, resampled or edited by hand.

| split | benign | malignant | total | origin in MMOTU |
|---|---|---|---|---|
| train | 713 | 87 | 800 | original `train` |
| validation | 178 | 22 | 200 | original `train` |
| test | 421 | 48 | 469 | original `val` |
| **total** | 1312 | 157 | 1469 | |

- The 469 images of the original MMOTU `val` subset form the `test` set, reserved for final evaluation.
- The 1000 images of the original MMOTU `train` subset are divided into `train` (800) and `validation` (200).
- The code that originally produced the 800 / 200 subdivision is not available in this repository. No sampling method or seed is claimed for it. The class proportions of the frozen partition were verified afterwards.

## Files

### `mmotu_experimental_split.csv` – canonical manifest

The canonical manifest of the project. It records identity, labels and partition for each sample.

| Column | Description |
|---|---|
| `image_id` | Sample identifier. |
| `image_name` | Image file name. |
| `mask_name` | Reference mask file name (`<image_id>_binary.PNG`). |
| `original_split` | Origin of the sample in MMOTU (`train` = original train, `validation` = original val). |
| `original_class` | Original MMOTU diagnostic category (0–7). |
| `binary_label` | Binary label (0 = benign, 1 = malignant). |
| `binary_class` | Binary class name (`benign` / `malignant`). |
| `experimental_split` | Use of the sample in the thesis (`train` / `validation` / `test`). |
| `legacy_split` | Name of the split in the previous manifest. |
| `experimental_image_path` | Image path in the experimental copy, relative to the project root. |
| `experimental_mask_path` | Mask path in the experimental copy, relative to the project root. |

Paths point to the organized experimental copy (`data/processed/MMOTU_OTU_2D_experimental/`), not to `data/raw/`.

It is generated by `notebooks/R2_dataset/06_generacion_split_experimental.ipynb` from the legacy manifest by renaming the splits only. The same notebook verifies the partition.

### `legacy/mmotu_experimental_split_legacy.csv` – previous manifest

The previous version of the manifest, preserved unchanged for traceability. It uses the former split names:

| Legacy name | Current name |
|---|---|
| `train_internal` | `train` |
| `val_internal` | `validation` |
| `final_validation` | `test` |

### `mmotu_experimental_split_standard.csv` – compatibility file

A file with the same membership and labels as the canonical manifest, using the original column `source_split` instead of `original_split`. It is kept unchanged because experiments already executed reference it:

- `src/classification/run_experiment.py`;
- `tests/test_classification_abc_integration.py`;
- R4 and R5 notebooks;
- the `run_config.json` files in `results/classification/formal/`.

It must not be modified. Notebook 06 verifies that its membership is identical to that of the canonical manifest.

## Related files

- `results/dataset/mmotu_experimental_technical_metadata.csv`: technical properties (dimensions, channels, format, mask values, image–mask correspondence) recalculated from the experimental copy, linked by `image_id`. It is not the original `metadata.csv` generated from `data/raw/`.
